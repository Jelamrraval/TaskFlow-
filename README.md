# ✅ TaskFlow - To-Do List Manager

A modern and responsive To-Do List Manager built using **HTML, CSS, and JavaScript**. TaskFlow helps users organize daily tasks with a clean glassmorphism interface, dark/light mode, task filtering, searching, progress tracking, and local storage support.

---

## 📖 Description

TaskFlow is a lightweight productivity application that allows users to create, manage, update, and delete tasks directly in the browser. All tasks are stored using **Local Storage**, ensuring data remains available even after refreshing or reopening the browser.

---

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks with confirmation
- ✅ Mark tasks as completed
- 🔍 Search tasks instantly
- 📂 Filter by All, Pending, and Completed
- 📊 Task statistics dashboard
- 📈 Progress bar with completion percentage
- 🌙 Dark & ☀️ Light theme toggle
- 🕒 Live date and time display
- 💾 Automatic Local Storage saving
- 🔔 Toast notifications
- 📱 Fully responsive design
